# TCP Port Scanner

## Overview

This project is a Python TCP port scanner that scans a target host for open TCP ports.

## Features

- Scans a user-specified host and port range
- Detects open TCP ports
- Displays scan results in the console

## Technologies

- Python 3
- socket library

## How to Run

python3 Portscanner.py

## Example

Target: 127.0.0.1

Open Ports:
22/tcp
80/tcp
443/tcp

## Educational Purpose

This project was created to learn:
- Socket programming
- Port scanning techniques
- Python network automation
